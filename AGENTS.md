This is an Expo/React Native mobile application. Prioritize mobile-first patterns, performance, and cross-platform compatibility.

## Expo version and documentation

The project uses Expo SDK 58. Before changing Expo, EAS, Expo Router, or React Native APIs, consult the matching versioned docs at https://docs.expo.dev/versions/v58.0.0/ and the index at https://docs.expo.dev/llms.txt. Do not assume APIs from older SDK versions still apply.

## Commands

This repository uses npm (package-lock.json is committed).

- npx.cmd expo install <package> on Windows PowerShell, to resolve SDK-compatible versions.
- npx.cmd expo start to run the development server.
- npx.cmd expo lint to run lint.
- npx.cmd tsc --noEmit to run TypeScript checks.
- npx.cmd expo-doctor to diagnose dependency and config issues.
- npx.cmd expo install --fix to fix incompatible package versions.

Run lint and typecheck before declaring a code change complete. If you cannot run them, state that clearly.

## Navigation and routing

Use Expo Router. In this repository, route files live in the root-level app/ directory (not src/app/). Every route file inside app/ is a screen; _layout.tsx files define navigators. Keep non-route code (components, hooks, utilities) outside app/.

Import Link, router, and useLocalSearchParams from expo-router.

## Building

Use Expo's cloud build and submission services for iOS and Android. EAS Build and EAS Submit do not require local Xcode or Android Studio when using cloud builds.

## Native project files

If ios/ and android/ directories do not exist, they are generated by Continuous Native Generation. Do not create or edit them manually. Configure native behavior through app.json and config plugins.

Expo Go includes only its bundled native modules. After adding a library with native code, use a development build rather than assuming it will run in Expo Go. Prefer Expo modules and use npx.cmd expo install to install compatible versions.
